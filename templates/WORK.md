## Acceptance and evidence

| Requirement | Smallest meaningful check | Actual result | Evidence and revision |
| --- | --- | --- | --- |
| TO BE SET | TO BE SET | Not run | TO BE SET |

Record the exact command and target. Mark emulation and physical-device checks
separately. Explain skipped checks and unresolved limits.
See [validation levels](../docs/validation.md#validation-matrix).

For accepted tasks, link the DONE file and updated milestone assessment under
[Task flow](../docs/task-flow.md#acceptance-and-completion). Record goal and overall
credit changes, or explain why useful intermediate work earns no credit yet.
Discovered work belongs in task files; this record links them without becoming
a second active backlog.
