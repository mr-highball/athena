# Milestone template

[Home](../README.md) · [Task flow](../docs/task-flow.md) · [Copying](README.md#copying-templates)

Adapt the following structure into the project's canonical milestone file.
Replace placeholders and add real relative links to goals, task files and evidence.
This template contains no assessed project progress.
